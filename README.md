# Digital Camera Atlas

Interactive Three.js educational prototype showing how a digital camera turns light into a stored image.

## V1
- Rotate / zoom
- Click Lens, Aperture, Shutter, CMOS Sensor, Processor, Memory Card
- Component explanations and highlighting
- Exploded view / reassemble
- X-ray body
- Animated Take Photo sequence

## Local preview
```bash
npm install
npm run dev
```

## Next milestone
Replace the procedural shell with a properly licensed realistic CC0 camera model, then add the Camera Lab for aperture, shutter speed and ISO.
